# BH_Parv

یک نسخه‌ی ساده‌تر و راحت‌تر از پروژه‌ی اصلی برای نصب و راه‌اندازی سریع‌تر تانل‌ها.

تمرکز این نسخه روی این است که کاربر بتواند با کمترین مراحل، پروژه را نصب و تانل‌های موردنیاز خود را راه‌اندازی و مدیریت کند.

- 🚀 نصب سریع با یک دستور
- ⚡ راه‌اندازی ساده‌تر تانل‌ها
- 🛠️ کاهش مراحل موردنیاز برای Setup
- 📦 مناسب برای نصب سریع روی سرور
- 🔧 ساده‌سازی فرآیند Configuration

## 📥 نصب

برای نصب کافی است دستور زیر را در ترمینال اجرا کنید:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/ParvaneZone/BH_Parv/main/install.sh)"
```

> 💡 در GitHub می‌توانید با کلیک روی آیکون **Copy** کنار کد، دستور نصب را مستقیماً کپی کنید.

پس از اجرای دستور، اسکریپت نصب اجرا شده و مراحل موردنیاز برای Setup را در اختیار شما قرار می‌دهد.
