## 📥 نصب

برای نصب کافی است دستور زیر را در ترمینال اجرا کنید:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/ParvaneZone/BH_Parv/main/install.sh)"
```

پس از اجرای دستور، اسکریپت نصب اجرا شده و مراحل موردنیاز برای Setup را در اختیار شما قرار می‌دهد.

## 🆕 ترنسپورت kcpmux و ابزارهای جدید

- **kcpmux**: ترنسپورت روی KCP (UDP) با رمزنگاری AES-256 از روی `token`. برای خطوط پرلاس مناسب است. پورت تانل **UDP** است و هر دو سر باید از همین فورک باشند.
- **گزینه ۸ منو: تست UDP** — روی سرور ایران «Receiver» و روی سرور خارج «Sender» را اجرا کنید تا بازبودن UDP مشخص شود.
- **گزینه ۹ منو: بررسی و رفع پیش‌نیازها** — اسکریپت خودش `curl`, `tar`, `openssl`, `python3`, `ss`, `sha256sum` و ca-certificates را قبل از نصب آماده می‌کند.
- **wss/wssmux**: اثرانگشت گواهی (`tls_pin`) خودکار داخل رشته‌ی اتصال کلاینت قرار می‌گیرد.
- دانلود باینری با `checksums.txt` ریلیز تأیید می‌شود.
- پنل وب (`web_port`) و pprof فقط روی `127.0.0.1` باز می‌شوند. دسترسی از راه دور: `ssh -L 2060:127.0.0.1:2060 user@server`

## ⚠️ وضعیت و هشدارهای مهم

- **این فورک هنوز در محیط واقعی تست نشده است.** ترنسپورت `kcpmux` تجربی است؛ قبل از استفاده‌ی جدی حتماً روی یک جفت سرور آزمایشی امتحان کنید. فهرست کامل تغییرات و محدودیت‌ها در `CHANGES-PARV.md` است.
- **ترنسپورت‌های `tcp`، `tcpmux`، `udp`، `ws` و `wsmux` رمزنگاری ندارند**؛ توکن و ترافیک روی خط قابل‌مشاهده است. برای مسیرهای حساس از `wssmux`/`wss` (با `tls_pin`) یا `kcpmux` استفاده کنید. پیش‌فرض منیجر `wssmux` است.
- `kcpmux` رمزنگاری دارد ولی احراز یکپارچگی واقعی (MAC) ندارد و کلیدش فقط از `token` مشتق می‌شود؛ توکن را تصادفی و بلند (حداقل ۱۲ کاراکتر، پیشنهاد: `openssl rand -hex 16`) بگذارید.
- **زنجیره‌ی تأمین:** نصب‌کننده و منیجر به‌صورت پیش‌فرض از شاخه‌ی `main` و آخرین ریلیز دانلود می‌کنند و `checksums.txt` از همان ریلیز می‌آید (فقط خرابی دانلود را تشخیص می‌دهد). برای امنیت بیشتر نسخه را قفل کنید و هش را از کانال مستقل بگیرید یا خودتان از سورس بسازید:

```bash
BH_REF=<tag-یا-commit> bash -c "$(curl -fsSL https://raw.githubusercontent.com/ParvaneZone/BH_Parv/<tag-یا-commit>/install.sh)"
BH_VERSION=vX.Y.Z BH_SHA256=<sha256-مستقل> ParvBH      # گزینه‌ی ۴ منو
```
